Gustify

Gustify is a cooking app for Chile. It ranks a curated recipe catalog by what is already in your pantry and leaves out recipes that conflict with an allergy you declared. The backend is FastAPI on PostgreSQL, and the match score is plain weighted arithmetic. I also built a Gemini recipe generator, but it is switched off in the deployed app.

How it is built

How it works

  • Match score without a model. Each recipe card shows how many of its ingredients you already have, plus a 0–100 score for the lens you pick (Para ti, Confort, Aventura, Skill, Reposado or Rápido). Each lens is a fixed weighted formula over pantry coverage, your cooking history, active filters and cooking time. Pantry coverage counts in every lens.
  • Allergen wall in SQL. Declared allergies are applied in the query's WHERE clause, before any scoring. A recipe is excluded if its allergen codes or any of its ingredients conflict with one of them, and opening an excluded recipe directly by its id returns 403. The allergen codes are derived from the ingredients, never typed by hand.
  • Curated catalog as code. Recipes are JSON files in the repo, written offline in AI-assisted development sessions (Claude) and never generated at request time. CI checks them (unique slugs, known ingredient codes, complete steps). On each deploy the API syncs the database to the files by slug, under a Postgres advisory lock. A search with no results can be saved as a request (one per user per hour), and a script turns pending requests into a brief for the next authoring session.
  • Cooking sessions saved on the server. Checked steps, the step timer and the cook's photos are stored per cooking session; photos are compressed in the browser and stored in Postgres. A reload or navigating away resumes the session where it was left.
  • Gemini generator: built, switched off. A recipe generator using Gemini through google-genai, with a Pydantic response schema, is in the code. RECIPE_CREATION_ENABLED is False, so its routes answer 403. The only override is for the test lane, and the deployed app's config refuses to boot with it on.
